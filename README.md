# 🎓 মুগ্ধ'র ইংলিশ মাস্টার (Mugdho's English Master)
### Class 4 English for Today (Units 11–18) & Board Exam Practice Platform

একটি আধুনিক, দ্রুতগতির এবং সম্পূর্ণ মোবাইল-বান্ধব ইন্টারেক্টিভ ওয়েব অ্যাপ—যা চতুর্থ শ্রেণির ইংরেজি চূড়ান্ত পরীক্ষার শতভাগ প্রস্তুতির জন্য বিশেষভাবে তৈরি।

---

## 🌟 প্রধান বৈশিষ্ট্যসমূহ (Key Features)

1. **৪টি বিষয়ের মোট ৪,০০০টি প্রশ্ন ও উত্তর (1,000 Questions per Topic):**
   - ⚡ **Right Form of Verbs:** ১,০০০টি প্রশ্ন (টেন্স ইন্ডিকেটর, Subject-Verb Agreement, Modals, Infinitives)।
   - 🧩 **Rearrange Sentences:** ১,০০০টি প্রশ্ন (Assertive, Interrogative, Exclamatory বাক্যের ইন্টারঅ্যাক্টিভ ট্যাপ ও সাজানো)।
   - 🅰️ **Articles (A, An, The & No Article):** ১,০০০টি প্রশ্ন (ধ্বনি ও উচ্চারণভিত্তিক ব্যতিক্রম যেমন University, European, Honest, Hour, MP ইত্যাদি)।
   - 📍 **Prepositions:** ১,০০০টি প্রশ্ন (At, In, On, To, By, For, Under, Behind, Between, Among ইত্যাদি)।

2. **প্রতিটি প্রশ্নে বিস্তারিত ব্যাখ্যা (Detailed Bangla Explanation):**
   - প্রতিটি প্রশ্নে সঠিক উত্তরের পাশাপাশি **সহজ বাংলা অর্থ (Translation)** এবং **"কেন এই উত্তর হলো?" (Detailed Logical Grammar Rule)** যুক্ত রয়েছে।

3. **ইন্টারেক্টিভ ড্র্যাগ ও ট্যাপ মোড (Rearrange Word Chips):**
   - ছোট বাচ্চাদের উপযোগী বড় ও স্পষ্ট ওয়ার্ড চিপস। ট্যাপ করলেই বাক্য তৈরি হয়ে যায়!

4. **ভুল উত্তরের খাতা (Mistakes Notebook):**
   - যে প্রশ্নগুলোতে ভুল হবে, সেগুলো স্বয়ংক্রিয়ভাবে ভুল খাতায় জমা থাকে।
   - সেখান থেকে **"শুধু ভুলগুলো প্র্যাকটিস করো"** বাটনে ক্লিক করে দুর্বলতাগুলো দ্রুত সংশোধন করা যায়।

5. **টাইমারসহ মডেল টেস্ট (Exam Mode):**
   - ৫, ১০, ২০ বা ৪০ মিনিটের রিয়েল এক্সাম সিমুলেশন।
   - পরীক্ষা শেষে ইনস্ট্যান্ট মার্কশিট, গ্রেড (A+, A), এবং স্কোর রিপোর্ট।

6. **গেমিফিকেশন ও সাউন্ড (Gamification & Offline Audio):**
   - Web Audio API চালিত চিম ও ফ্যানফেয়ার (কোনো এক্সটার্নাল অডিও ফাইলের লোডিং ঝামেলা নেই)।
   - প্রতিদিনের স্ট্রিক (🔥 Daily Streak) এবং স্টার পয়েন্ট (⭐ Star Points)।
   - ব্যাজ ও ট্রফি আনলক সিস্টেম।

7. **১০০% অফলাইন এবং কোনো সার্ভার প্রয়োজন নেই (Pure Static Client-Side):**
   - কোনো ডেটাবেজ বা ব্যাকএন্ড ছাড়াই সরাসরি মোবাইল ব্রাউজারে কাজ করে।
   - PWA প্রস্তুত—মোবাইলে **"Add to Home Screen"** করলেই অ্যাপের মতো ইনস্টল হয়ে যায়।

## 🚀 গিটহাব ও নেটলিফাইয়ে লাইভ করার নিয়ম (GitHub & Netlify Deployment Guide)

### ধাপ ১: GitHub এ আপলোড
1. GitHub-এ একটি নতুন রিপোজিটরি তৈরি করুন (যেমন: `mugdho-english-master`).
2. এই ফোল্ডারের ফাইলগুলো গিটহাবে পুশ করুন:
   ```bash
   git init
   git add .
   git commit -m "Initial commit of Mugdho English Master"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/mugdho-english-master.git
   git push -u origin main
   ```

### ধাপ ২: Netlify এর সাথে কানেক্ট করা (মাত্র ১ মিনিট)
1. [Netlify.com](https://www.netlify.com) এ লগইন করুন।
2. **"Add new site"** ➜ **"Import an existing project"** ➜ **"GitHub"** সিলেক্ট করুন।
3. আপনার রিপোজিটরিটি (`mugdho-english-master`) নির্বাচন করুন।
4. বিল্ড সেটিংস:
   - **Build command:** *(ফাঁকা রাখুন / Leave blank)*
   - **Publish directory:** `.` *(বা রুট ফোল্ডার)*
5. **"Deploy site"** বাটনে ক্লিক করুন!
6. নেটলিফাই তাৎক্ষণিকভাবে একটি লাইভ লিঙ্ক দিয়ে দেবে (যেমন: `https://mugdho-english-master.netlify.app`)।

👉 এবার এই লিঙ্কটি ভাগনে মুগ্ধ'র মোবাইলে পাঠিয়ে দিন। সে যেকোনো ব্রাউজারে (Chrome বা Safari) ওপেন করলেই তাৎক্ষণিক প্র্যাকটিস করতে পারবে!

## 📱 মোবাইলে অ্যাপ হিসেবে ব্যবহারের নিয়ম (Add to Home screen)
1. মোবাইলের Chrome ব্রাউজারে সাইটের লিঙ্কটি ওপেন করুন।
2. ব্রাউজারের উপরে ডানদিকের তিনটি ডট (⋮) মেনুতে চাপ দিন।
3. **"Install app"** বা **"Add to Home screen"** চাপুন।
4. মোবাইলের হোম স্ক্রিনে অ্যাপ আইকন তৈরি হয়ে যাবে!
